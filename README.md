# 📚 SmartLib – Student Library Management System

**SmartLib** is a web-based library management system designed for **students** using **HTML** and **Tailwind CSS**.  
It allows students to:

- Search for books  
- Borrow available books  
- Reserve unavailable books  
- Track borrowing history  
- Receive notifications about due dates  

The system is inspired by world-class libraries such as the **Library of Congress**, **British Library**, and **Bibliothèque nationale de France**.  

---

## 1. Background

Many educational libraries still rely on manual systems to:

- Register students  
- Record borrowed books  
- Track returns  
- Manage book availability  

These manual processes often lead to:

- Loss of records  
- Time-consuming operations  
- Book misplacement  
- Difficulty tracking borrowed books  

**SmartLib** provides a modern, digital solution to help students manage their library interactions efficiently.  

---

## 2️. System Users

###  Students

Students can:

- Create an account and log in  
- Search books by title, author, or category  
- Borrow books and track due dates  
- Reserve books that are currently unavailable  
- View borrowing history  
- Receive notifications for upcoming returns  

---

## 3️. System Pages (HTML + Tailwind CSS)

1. **Home Page** – Navigation, featured books, about section  
2. **Login Page** – Email and password form  
3. **Registration Page** – Name, email, student ID, password  
4. **Book Catalog Page** – Search bar, book cards, borrow/reserve buttons  
5. **Student Dashboard** – Welcome message, borrowed/reserved books, history  
6. **Borrow History Page** – List of borrowed books and due dates  
7. **Notifications Page** – Alerts for upcoming returns or availability  

---

## 4️. Example Scenario

1. A student logs into **SmartLib**  
2. Searches for a book, e.g., *Database Systems*  
3. Clicks **Borrow** if available  
4. System records borrowing date (e.g., 14 days)  
5. If the book is not returned on time → notifications are sent  

---

## 5️. Non-Functional Requirements

- Responsive design (works on mobile, tablet, desktop)  
- Clean and intuitive user interface (Tailwind CSS)  
- Fast book search and filtering  
- Secure login and registration
